# -Lasso-Ridge-and-Elastic-Net-Regression
This project demonstrates the implementation and comparison of three popular regularization techniques used in Machine Learning:  - **Lasso Regression (L1 Regularization)** - **Ridge Regression (L2 Regularization)** - **Elastic Net Regression (L1 + L2 Regularization)**
uture Improvements

- Hyperparameter tuning using GridSearchCV
- Cross-validation
- Feature engineering
- Pipeline implementation
- Model deployment using Flask or Streamlit
